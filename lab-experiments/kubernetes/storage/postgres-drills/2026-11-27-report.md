## Changes the drill forced

`restore.sh` assumed docker and the default kubectl context. The workstation had neither, so the script now falls back to a local `aws` CLI and reads `KUBE_CONTEXT`. The local client was 2.42.4, not the pinned 2.36.1, and worked with the same two checksum variables.
